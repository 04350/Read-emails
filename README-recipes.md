# המתכונים שלי — מנהל מתכונים מקומי

יישום שולחני בעברית ל-Windows 10/11. לאחר בניית ה-EXE אין צורך ב-Python, בהתקנת רכיבים או בחיבור אינטרנט.

## מה כלול
- ייבוא קבצים בודדים או תיקייה שלמה, כולל כל תתי-התיקיות.
- גרירה ושחרור של קבצים/תיקיות לחלון.
- קוראי PDF עם שכבת טקסט, Word DOCX, OpenDocument ODT, TXT, Markdown, RTF, HTML ו-CSV.
- איתור כותרת בתחילת המסמך ושמירת עותק בשם הכותרת (עם מספור אם יש שם כפול).
- SQLite מקומי וחיפוש שמעדיף שם מתכון על פני טקסט מלא.
- חיפוש שמתעלם מניקוד עברי וסימני פיסוק, התאמת כל מילות החיפוש וסבילות מוגבלת לשגיאות הקלדה בכותרת.
- שינוי שם, פתיחת קובץ, מחיקה וגיבוי ZIP.
- המידע נשמר ב-%LOCALAPPDATA%\HaMitkonimSheli ולא בתוך קובץ ה-EXE, כדי שלא יימחק בעדכון התוכנה.

## מגבלות
- PDF שהוא תמונה/סריקה בלבד לא ייקלט. לא מתבצע OCR.
- מסמכים מוגני סיסמה או פגומים עלולים להיכשל; הייבוא מציג פירוט שגיאות.
- זיהוי הכותרת הוא היוריסטי: עובד הכי טוב כשהכותרת מופיעה בתחילת המסמך.
- בניית הקובץ מתבצעת ב-GitHub Actions על Windows. המחשב שמריץ את ה-EXE אינו צריך אינטרנט.

## בנייה
GitHub Actions מריץ Windows build ב-push לענף `recipe-manager-build` או בהפעלה ידנית. התוצר זמין כ-Artifact בשם `HamitkonimSheli-Windows-EXE`.

## פרטיות
היישום אינו כולל שליחת נתונים, analytics, telemetry או קריאות רשת. מסד הנתונים, עותקי הקבצים והגיבויים נשארים במחשב המשתמש.
