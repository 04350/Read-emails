# Read-emails — מעקב פתיחת מיילים ב־Gmail

## מה התוכנה עושה?

Read-emails הוא סקריפט שמוסיף ל־Gmail אפשרות לעקוב אחר פתיחת מיילים שנשלחו. הממשק כולו בעברית, והוא מציג מידע בצורה פשוטה ונוחה, ישירות בתוך Gmail.

### התכונות העיקריות

- **סימון מיילים שנפתחו** — הצגת חיווי ליד מיילים בתיקיית הדואר שנשלח.
- **הצגת פרטי פתיחה** — אפשר לראות מתי זוהתה פתיחה וכמה אירועי פתיחה נרשמו.
- **חלונית צד בעברית** — הצגת הפרטים בצורה מרוכזת ונוחה.
- **תמיכה בשליחת מיילים** — כולל ניסיון תמיכה בשליחה באמצעות קיצור המקשים Ctrl+Enter.
- **ממשק בעברית** — הסימונים והמידע מוצגים בעברית, בתוך Gmail.

## איך זה עובד?

הסקריפט מותקן באמצעות Tampermonkey, תוסף שמאפשר להפעיל סקריפטים מותאמים אישית בדפדפן.

בעת שליחת הודעה, הסקריפט מוסיף לה תמונת מעקב זעירה. כאשר התמונה נטענת, נשלח אירוע לשירות המעקב, והמערכת יכולה להציג את מועד האירוע ואת מספר האירועים שנרשמו.

המערכת משתמשת ב־Cloudflare Worker וב־Workers KV לשמירת אירועי המעקב ולהצגתם בחלונית.

## התקנה והגדרה

אין צורך להתחבר לחשבון נוסף כדי להשתמש בממשק. עם זאת, בגרסה הנוכחית נדרשת הגדרה ראשונית של כתובת שירות המעקב ושל מפתח הגישה, לפני שהמעקב יפעל.

## פרטיות ומגבלות

יש להגדיר שירות מעקב ומפתח גישה אישיים. אין לשתף מפתח אישי בפרסום ציבורי.

חשוב לדעת: זיהוי טעינת תמונת המעקב אינו הוכחה ודאית שאדם קרא את המייל. שירותי סינון, שרתי תמונות ותוכנות אבטחה עלולים לטעון את התמונה באופן אוטומטי. בנוסף, אם תמונות חסומות או אינן נטענות, ייתכן שלא יירשם אירוע פתיחה.

הסקריפט נועד להוסיף יכולת שימושית ל־Gmail, והממשק שלו בעברית ובתוך סביבת העבודה המוכרת של Gmail.
