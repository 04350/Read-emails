# Read-emails — מערכת למעקב אחר פתיחת מיילים ב־Gmail

רוצים לדעת אם מייל ששלחתם נפתח? הכירו את **Read-emails**, סקריפט שמוסיף ל־Gmail אפשרות למעקב אחר פתיחות מיילים, עם ממשק בעברית.

### מה הסקריפט מאפשר?

- **מעקב אחר פתיחות:** זיהוי פתיחה של מיילים שנשלחו, באמצעות תמונת מעקב.
- **תצוגה בעברית:** סימונים ומידע המוצגים בתוך Gmail.
- **חלונית צד:** ממשק נוח לצפייה באירועי הפתיחה שנאספו.
- **מידע על מועדי פתיחה:** הצגת מועדי הפתיחה שזוהו, בהתאם לנתונים שהתקבלו משירות המעקב.

### איך מתקינים?

**שלב 1 — התקנת Tampermonkey**

יש להתקין את התוסף Tampermonkey בדפדפן התומך בו.

**שלב 2 — התקנת הסקריפט**

פותחים את קישור ההתקנה הבא:

https://raw.githubusercontent.com/04350/Read-emails/main/read-emails-sidebar.user.js

Tampermonkey אמור להציג את מסך ההתקנה של הסקריפט. בודקים את הקוד ומאשרים את ההתקנה.


### כמה דברים שחשוב לדעת

- שירות המעקב צריך להיות מוגדר ופועל כדי לאסוף ולהציג אירועי פתיחה.
- מערכות אבטחה, סינון תמונות ושרתי דואר עשויים לטעון תמונות באופן אוטומטי. לכן, אירוע פתיחה אינו הוכחה ודאית שאדם קרא את המייל.
