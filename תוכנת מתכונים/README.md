# תוכנת המתכונים שלי

יישום שולחני בעברית ל-Windows 10/11. לאחר בניית קובץ ה-EXE אין צורך ב-Python, בהתקנת רכיבים או בחיבור אינטרנט.

## שימוש
- ייבוא קבצים בודדים או תיקייה שלמה, כולל תתי-תיקיות.
- גרירה ושחרור של קבצים ותיקיות לחלון.
- איתור כותרת ושמירת עותק בשם הכותרת, תוך מניעת דריסה של קובץ קיים.
- מסד נתונים SQLite מקומי וחיפוש שמעדיף התאמה בשם המתכון על פני התאמה בגוף המתכון.
- חיפוש שמתעלם מניקוד עברי וסימני פיסוק, ומסוגל לבצע התאמות גמישות במידה מוגבלת.
- שינוי שם, פתיחת קובץ, מחיקה וגיבוי ZIP.
- המידע נשמר ב-%LOCALAPPDATA%\\HaMitkonimSheli ולא בתוך קובץ ה-EXE, כדי שלא יימחק בעדכון התוכנה.

## סוגי קבצים
PDF עם שכבת טקסט, Word DOCX, OpenDocument ODT, TXT, Markdown, RTF, HTML ו-CSV.

PDF שהוא תמונה/סריקה בלבד אינו נקלט. התוכנה אינה משתמשת ב-OCR. מסמכים מוגני סיסמה או פגומים עלולים להיכשל. זיהוי הכותרת עובד בצורה הטובה ביותר כשהיא מופיעה בתחילת המסמך.

## עבודה ללא אינטרנט
כל הספריות הדרושות לקריאת הקבצים נארזות בתוך ה-EXE. מחשב המשתמש אינו זקוק לאינטרנט בזמן ההתקנה או ההפעלה, ואין שליחת נתונים, analytics או telemetry.

## בנייה
תהליך הבנייה האוטומטי מוגדר ב-GitHub Actions בקובץ `.github/workflows/build-windows.yml` שבשורש המאגר. GitHub דורש שקובצי workflow יישבו בתיקייה הזאת כדי להפעילם; כל קוד התוכנה, ההוראות וקובצי ההגדרות נמצאים בתיקייה `תוכנת מתכונים`.

הבנייה מתבצעת על Windows ומעלה Artifact בשם `HamitkonimSheli-Windows-EXE`.

## פרטיות וגיבוי
מסד הנתונים, עותקי הקבצים והגיבויים נשארים במחשב המשתמש. מומלץ לגבות מדי פעם את תיקיית הנתונים המקומית.
